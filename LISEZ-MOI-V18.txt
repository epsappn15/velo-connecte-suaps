SUAPS POITIERS – VELO CONNECTE – V1.8

Cette version ajoute les icones de marque pour le navigateur et l'ecran d'accueil, ainsi que le manifeste d'application web.

Fichiers ajoutes dans public/ :
- favicon.ico, favicon-16.png, favicon-32.png : icone d'onglet / navigateur
- apple-touch-icon.png : icone pour l'ecran d'accueil iPhone/iPad
- icon-192.png et icon-512.png : icones pour installation sur appareils compatibles
- manifest.webmanifest : nom, couleurs, icones et mode d'affichage de l'application installee

Aucune modification des donnees, des routes API ou du schema Turso n'est necessaire.
Conserver les variables d'environnement Render existantes.

Installation : remplacer les fichiers du depot par le contenu de cette archive et deployer la branche main.

Sur iPhone/iPad : ouvrir l'application dans Safari > bouton Partager > Sur l'ecran d'accueil > Ajouter.
Sur ordinateur/Android : utiliser l'option Installer l'application si elle est proposee par le navigateur.
Le favicon de l'onglet peut rester en cache ; recharger la page et, si besoin, vider le cache du navigateur.
